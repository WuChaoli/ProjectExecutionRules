# Python Rules

## 事实来源

- `PY-001`：Python 版本、依赖、包管理器和工具必须从项目元数据、锁文件和 CI 确认。

## 执行规则

- `PY-002`：公共接口使用明确类型，避免导入时产生网络或进程副作用。
- `PY-003`：依赖通过项目已经采用的包管理器修改并同步锁文件。
- `PY-004`：格式、Lint、类型检查和测试使用项目实际配置的工具。
- `PY-006`：源码入口和包边界必须以当前项目结构及项目元数据为准，不假设固定目录。

## 验证要求

- `PY-005`：Rules 只描述验证入口；执行项目质量命令不属于 Rules CLI 职责。

## 职责边界

通用测试、架构和外部服务原则分别由对应 Core Rules 管理。
