# Security Rules

## 事实来源

- `SEC-001`：权限、凭据和外部副作用必须以真实配置及当前授权为准。

## 执行规则

- `SEC-002`：禁止读取、输出或提交 `.env`、密钥、令牌、PID、日志和本机运行状态。
- `SEC-003`：破坏性操作必须先解析并验证精确目标，不得使用宽泛根目录。
- `SEC-004`：超出用户授权范围的写入、外部请求或权限变化必须停止。

## 验证要求

- `SEC-005`：交付前必须检查变更中不存在凭据、运行状态和越权文件。

## 职责边界

具体工具权限由 Tool Rules 管理；本文件只定义不可降级的安全内核。
